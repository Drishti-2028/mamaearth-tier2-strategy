# Mamaearth Tier-2 Market Entry Strategy

## 📊 Overview
This project presents a strategic consulting analysis for Honasa Consumer Ltd (Mamaearth), focusing on scalable and profitable expansion into Tier-2 markets in India.

## 🎯 Problem Statement
Mamaearth’s current D2C model relies heavily on digital advertising (53% of revenue), leading to declining profitability and limited penetration in Tier-2 markets.

## 🔍 Key Insights
- Ad spend reached ₹1,102 Cr (53% of revenue) in FY25
- Net profit declined 35% YoY
- Tier-2 consumers are highly price-sensitive and prefer offline channels
- Limited General Trade presence restricts visibility

## 💡 Strategy Recommendations
- Launch ₹99–₹149 SKUs for Tier-2 affordability
- Expand into 50,000+ Kirana stores
- Replace celebrity marketing with regional micro-influencers
- Implement a strict 30% ad spend cap

## 📈 Expected Impact
- Projected ₹1,400 Cr Tier-2 revenue by FY28
- Improved profitability via reduced CAC and offline distribution

## 🛠 Tools & Skills Used
- Python (Pandas) for financial analysis
- Microsoft Excel (Screener.in data)
- Data Visualization & Strategic Frameworks (SWOT, PESTLE)
- PowerPoint for consulting-style presentation
